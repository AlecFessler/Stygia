# Dead-code analyzer skip list for kernel/.
#
# Canonical format (symbol-anchored — preferred):
#   entity:<file>::<qualified_name>    sha256:<hex>
#     * <file> is the DB-canonical path (matches `file.path`).
#     * <qualified_name> is `entity.qualified_name` from the callgraph DB.
#     * <hex> is sha256 over the entity's NORMALIZED def-span content
#       (comment-stripped, trailing-whitespace-stripped, EOL-normalized,
#       trailing blank lines dropped). See tools/dead_code_zig/src/main.zig
#       top-of-file doc comment for the exact normalization rules.
#     * Survives line shifts caused by upstream edits; invalidates only on
#       rename or content mutation.
#
# Legacy format (line-range — preserved only for entries that don't bind
# to a single entity; new entries should use the symbol form):
#   <relpath>:<start>-<end>    sha256:<hex>
#     * Hash is over joined raw line bytes [start..end] with \n EOLs and
#       a trailing \n. Brittle: any upstream edit shifting these line
#       numbers (or a whitespace edit on an anchored line) invalidates.
#
# Tooling:
#   * `dead_code_zig --update-skip <anchor>` recomputes one entry's SHA.
#     <anchor> may be either form.
#   * `dead_code_zig --rewrite-skip` migrates every legacy line-range
#     entry in this file to symbol form against the current DB. Run once
#     after any structural kernel edit to keep entries entity-anchored.
#   * If an anchor's content changes, the analyzer reports INVALIDATED on
#     stderr; re-review the change, then `--update-skip` to refresh.
#
# Why we skip rather than delete:
#   * caps/process.zig (ProcessCaps/IpcCaps) and libz/caps.zig
#     (SelfCap/IpcCap) — packed 16-bit kernel/userspace handle-cap ABIs.
#     Spec §[process] reserves self-cap bits 6-8 and IPC-cap bits 3-4;
#     deleting these fields would shift live restart and policy bits.
#   * arch/aarch64/acpi.zig, arch/x64/acpi.zig         — ACPI table layout fields.
#     We model the full struct so reads at fixed offsets are correct even when
#     today's code only consumes a subset. Deleting fields would corrupt the
#     binary layout.
#   * arch/aarch64/hv/regs.zig                        — EL2 sysreg bit-field
#     reference set (HCR_EL2 / VTCR_EL2 / VTTBR_EL2 / ESR_EL2 / CPTR_EL2 /
#     HPFAR_EL2 etc.). Kept whole so future EL2 bring-up grabs bits without
#     re-deriving from the ARM ARM.
#   * arch/x64/intel/vmx.zig, arch/x64/amd/svm.zig,
#     arch/x64/amd/vi.zig, arch/x64/intel/vtd.zig,
#     — Intel/AMD MSR / VMCS / VMCB / IOMMU encoding sets. Same reasoning: arch
#     reference set, kept whole. The VT-d RootEntry / ContextEntry
#     packed structs (vtd.zig) describe hardware-mandated 128-bit
#     entries — reserved fields stay so the binary layout matches what
#     the IOMMU walker expects on memory reads.
#   * arch/x64/cpu.zig                                 — CPUID feature bits.
#     A future feature probe should pick the bit from this enum, not redefine
#     it; keep the spec-mandated value space.
#   * arch/x64/apic.zig                                — LAPIC + x2APIC MSR
#     register space. Hardware-defined enum range.
#   * arch/x64/gdt.zig (Tss), arch/x64/idt.zig         — x86 hardware-mandated
#     descriptor layout; reserved fields and IST slots stay so the binary
#     layout matches the CPU's expectations.
#   * arch/x64/paging.zig, arch/aarch64/paging.zig     — page-table entry bits
#     (PageEntry). Hardware layout fidelity; flags like dirty/contiguous etc.
#     are read by the MMU even if the kernel never asserts them today.
#   * arch/aarch64/exceptions.zig (ExceptionClass),
#     arch/aarch64/hv/regs.zig (EC),
#     arch/aarch64/gic.zig                             — ARM ESR_EL1 / ESR_EL2
#     ExceptionClass / GICD register enum value spaces.
#   * arch/aarch64/interrupts.zig — register-block /
#     register-accessor parity. x18 is part of the AArch64 GPR file even when
#     the trap save path does not touch it.
#   * arch/x64/serial.zig (com2..com4), arch/x64/exceptions.zig
#     (invalid_execute), arch/x64/timers.zig                 — hardware port /
#     register / vector identifiers. Kept for hardware fidelity.
#   * arch/aarch64/vm.zig                              — aarch64 VmPolicy ABI
#     struct (id_reg_responses / sysreg_policies). Layout-defined ABI with
#     comptime size assertion; consumed by the EL2 trap handler when bring-up
#     resumes.
#   * arch/aarch64/hv/{vcpu,vm}.zig (_placeholder)    — page-sized control
#     state cells reserved for future EL2 vCPU / VM state.
#   * arch/x64/vm.zig                                  — VM policy padding
#     fields + sysregPassthrough helper reserved for VMX policy bring-up.
#   * arch/x64/interrupts.zig                          — SyscallScratch slots
#     used only by paths not yet wired in the spec-v3 transition.
#   * arch/x64/timers.zig                              — HPET capability /
#     config / status reserved fields.
#   * boot/protocol.zig                                — bootloader-handoff
#     padding for AArch64-EL2 placeholder slot.
#   * memory/address.zig (UserVA, null_guard)          — VA-space landmark
#     constants kept for the systems.md reference.
#   * sched/thread.zig (Priority.high)      — third tier of the
#     fixed-size priority enum; kept so .high is reachable when bring-up
#     wires it.
#   * syscall/errors.zig (E_REFUSED) — spec error code 13 reserved
#     for capability-refused conditions, no kernel returner yet.
#   * sched/priority_queue.zig (enqueueFront) — generic re-queue
#     helper documented for IPC cap-transfer rollback (kept until that
#     rollback path lands).
#   * memory/vmar.zig (CacheType.* / RestartPolicy.decommit) — VarRange
#     attribute / restart-policy enums; spec-mandated value space.
#   * memory/vmar.zig (mapping_table)                  — placeholder slot
#     for the eventual sparse offset → page-frame walk that backs
#     `map = page_frame` and `map = demand`; layout TBD.
#   * devices/device_region.zig (_pad0)                — explicit pad slot
#     in the DeviceRegion ABI struct.
#
